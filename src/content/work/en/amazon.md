## Problem

TV app experiences run under strict rendering, memory, and input constraints — most standard web performance playbooks don't apply, and navigation/focus handling has to be built from scratch for remote-control input.

## Action

Built end-to-end solutions used across multiple teams and by external customers: reference apps, focus and navigation systems, reusable components, and tooling for TV development. Worked against deep platform constraints — video performance, input models, rendering limits, layout strategies. Modernized telemetry clients across TypeScript, Go and Python, aligning cross-ecosystem behavior and shipping backward-compatible improvements that unblocked internal and third-party teams.

## Result

Tooling and components adopted by internal and external (3P) teams, unblocking work that previously required rebuilding the same systems per team, and raising the baseline for TV experience quality across the organization.
