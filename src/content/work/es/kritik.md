## Problema

Codebase de React y Redux fuertemente acoplado. Ciclos de iteración lentos, sin cobertura de pruebas automatizadas, una capa de datos difícil de razonar.

## Acción

Lideré el refactor del manejo de estado de Redux a React Query con TypeScript. Dividí componentes monolíticos para reutilización. Construí pruebas end-to-end con Cypress. Integré PostgreSQL con Prisma para limpiar la capa de datos.

## Resultado

Una capa de datos y arquitectura de componentes que el equipo pudo extender sin romper funcionalidad existente, con pruebas automatizadas detectando regresiones antes de llegar a producción.
